# Incident Response Process

## Severity levels
Sev1 is a customer-facing outage, Sev2 is partial degradation, Sev3 is a minor issue.

## Sev1 rules
For a Sev1, page the on-call engineer immediately, open a war-room channel within 10 minutes and publish a status page update within 30 minutes.

## Postmortems
A blameless postmortem is required within 5 working days of any Sev1.
